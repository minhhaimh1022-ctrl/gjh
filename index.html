Lưu Ý Kỹ Thuật Khi Chạy Internet Thực Tế

1. localStorage trình duyệt vs. Dữ liệu dùng chung đa thiết bị

Bản HTML tĩnh lưu dữ liệu bằng localStorage ngay trên trình duyệt của từng người dùng. Khi bạn đăng web lên internet:

  • Người dùng tự lưu Kho File & lịch sử trên thiết bị của họ.
  • Danh sách nhiệm vụ Admin tạo chỉ nằm trên trình duyệt của Admin trừ khi bạn dùng Xuất / Nhập JSON để chia sẻ hoặc nối thêm backend/database (Supabase, Firebase, Cloudflare KV...).
2. Link4m API & CORS khi chạy domain thật vs. localhost/sandbox

Khi chạy trên file:// hoặc khung preview cô lập, trình duyệt dễ chặn gọi trực tiếp API rút gọn hoặc chuyển hướng về trang đệm ?gate=1. Trên tên miền HTTPS thật (GitHub Pages, Cloudflare Pages, Vercel, Netlify), luồng chuyển hướng ?gate=1 và tự mở khóa ?unlock=... hoạt động ổn định nhất.

3. Nguyên tắc bảo mật phía client

Mật khẩu Admin (nhiemvufile) và API Token Link4m nằm ở phía trình duyệt/cấu hình cục bộ. Không dùng cho dữ liệu nhạy cảm cao hoặc tài sản có giá trị tài chính lớn nếu chưa có lớp xác thực máy chủ.
