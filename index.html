Kho File Free Đã Nhận

Lưu trữ toàn bộ link tải và mật khẩu giải nén đã mở khóa của tài khoản hiện tại.

Lịch sử nộp bằng chứng

Theo dõi trạng thái chờ duyệt, đã duyệt cấp file hoặc bị từ chối.

Đăng Lên Internet Thực Tế (GitHub Pages / Cloudflare / Vercel / Netlify)

Kiểm tra cấu hình, tải bản đóng gói index.html + .nojekyll + README.md, và xem hướng dẫn xuất bản miễn phí.

Đang kiểm tra môi trường...

1. Xuất bản nhanh qua GitHub Pages

  1. Tạo kho lưu trữ Public trên GitHub (ví dụ filequest) hoặc dùng kho hiện có.
  2. Tải file index.html (và .nojekyll) lên thư mục gốc nhánh main.
  3. Vào Settings → Pages, chọn nhánh main / / (root) rồi bấm Save.
  4. Đợi build hoàn tất, mở URL https://<user>.github.io/<repo>/ và dùng chính URL này làm URL gốc của web khi tạo link Link4m.

2. Tải gói triển khai & áp dụng URL gốc

Lưu ý: Dữ liệu nhiệm vụ và lịch sử lưu tại localStorage của từng trình duyệt. Nếu gọi API Link4m trực tiếp từ trình duyệt bị chặn CORS (Failed to fetch), hệ thống tự động thử proxy dự phòng hoặc dùng Worker riêng của bạn.
